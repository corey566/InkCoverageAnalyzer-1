## Main requirement

The app must estimate coverage using only **Black, Cyan, Magenta, and Yellow**.

The displayed percentages must be based on **page area**, and the total of the displayed categories must **not exceed 100%**.

## Correct calculation model

Treat the full page as 100% total area.

For each page:

1. Detect all printed, non-white regions.
2. Assign each printed pixel or small area to **one dominant CMYK bucket only**:

   * Black
   * Cyan
   * Magenta
   * Yellow
3. Make the classification **mutually exclusive** so that one pixel is counted only once.
4. Do not count the same area in multiple channels.
5. The sum of:

   * Black %
   * Cyan %
   * Magenta %
   * Yellow %

   must equal total page coverage, and must never exceed 100%.

## Important correction

Do **not** use additive CMYK channel totals for the main displayed results.

Wrong behavior:

* Cyan 62%
* Magenta 81%
* Yellow 84%
* Black 60%
* Total 288%

That is not acceptable for the user-facing display.

Correct behavior:

* Each displayed category must represent a unique portion of the page area.
* Adding Black + Cyan + Magenta + Yellow must stay at or below 100%.
* Blank area must be the remainder of the page.

## Results that should be shown

For each page and for the document average, show only:

* Page Coverage
* Blank Area
* Black %
* Cyan %
* Magenta %
* Yellow %

Formula:

* `Page Coverage = Black + Cyan + Magenta + Yellow`
* `Blank Area = 100 - Page Coverage`
