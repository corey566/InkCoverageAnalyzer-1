📄 1. PRODUCT REQUIREMENTS DOCUMENT (PRD)
Purpose

A promotional web application for printer distributors that estimates:

Ink coverage (CMYK or Color+Black)

Cost per page

Variation range

Core Features

File upload (PDF, JPG, PNG)

Coverage analysis

Two modes:

CMYK

Color + Black cartridge

Cost estimation:

user enters yield + price

Waste / variation adjustment

Result display:

coverage %

cost/page

range (± variation)

Non-Goals (important)

Not a RIP system

Not exact print simulation

Not driver-level emulation

Accuracy Positioning

“Profile-based estimation”

Not absolute 100% accuracy

Core Modules
1. Upload Service

validate file

create job

2. Processing Service

read file

convert pages to images

normalize color

calculate coverage

3. Coverage Engine

For each page:

for each pixel:
  extract CMYK values
  accumulate per channel

Coverage:

coverage = total_channel_value / max_possible_value
4. Cost Engine

Formula:

effective_yield = rated_yield × (5 / actual_coverage)
cost_per_page = price / effective_yield
5. Waste Adjustment
final_cost = base_cost × (1 + waste%)
